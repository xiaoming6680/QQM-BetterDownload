# 应用内验收

正常使用是：**安装一次，在 QQ 音乐中下载歌曲，等待自动输出。** 不需要先选目录，也不需要逐首点“查找并转换”。

本清单区分应用内实测与隔离测试。22.71 x86 的 GF 入口、HTML 页面和右下角卡片已显示；最后追加的交互修正仍需按下表实机复测。

## 设置与卡片

| 操作 | 预期结果 |
| --- | --- |
| 点击顶部 BetterDownload 图标 | HTML 设置页出现在内容区，保留 QQ 音乐侧栏、标题栏和播放器 |
| 首次打开设置（新安装，或从 0.1.3 升级后第一次） | 先显示“欢迎使用 BetterDownload”介绍与免责声明，设置项不出现；页面可滚动，淡入正常 |
| 在介绍页点击“同意并继续” | 介绍页淡出，设置页从顶部淡入；关闭再打开、重启 QQ 音乐后都直接进入设置 |
| 在介绍页点击“不同意并卸载” | 安装器的卸载确认窗口出现在最前；点“取消”后介绍页保持不变，未记为同意 |
| 点击页脚“免责声明” | 重新显示介绍页，按钮为“完成”，没有“不同意并卸载”；点“完成”或关闭再打开设置后回到设置页 |
| 再点同一图标，或在页面按 Esc | 返回 QQ 音乐 |
| 鼠标移入 / 按住入口 | 图标变客户端主题绿（悬停 / 按下），无底色方块；只在图标本身上变色、显示手形光标，图标旁的空白处没有变化 |
| 双击入口 | 不改变 QQ 窗口的最大化状态；只响应一次开关 |
| 关闭后重新打开设置 | 重新播放入场动效；正常切换设置项不重复播放整页动画 |
| 展开 / 收起 QQ 侧栏、缩放窗口 | 设置页跟随内容区，不覆盖侧栏 |
| 设置页打开时点击左侧列表，或左下角的菜单（设置）、换肤、侧栏按钮 | 设置页先关闭，再显示 QQ 的页面或菜单；从菜单打开的 QQ 设置等页面不被设置页挡住 |
| 切换通知、样式或停留时间 | 选项立即更新，QQ 界面不闪黑 |
| 首次打开、点击圆角按钮 | 圆角保持；鼠标点击不遗留蓝色焦点框，键盘操作保留焦点提示 |
| 预览期间连续切换标准 / 简洁 | 卡片保持右下角位置，尺寸与内容一起切换，无拉伸和旧画面残留；简洁卡片下方没有多余空白，标准卡片底部“打开文件夹”一行完整 |
| 滚动到页脚 | 作者、项目主页、问题反馈、免责声明、卸载间距清楚，路径只显示一个分隔符 |
| 点击页脚“卸载” | 安装器的卸载确认窗口出现在最前，带默认不勾选的“同时删除插件数据”；点“取消”后设置页不变 |
| 点击“预览” | QQ 音乐内部右下角显示转换卡片，然后显示完成 |
| 卡片外观 | 白底浅色卡片、柔和阴影、品牌绿进度与状态，与 QQ 浅色界面协调 |
| 鼠标悬停 / 移开 | 悬停保持，移开后按 2 / 4 / 6 秒计时收起 |
| 右键卡片 | 提前收起 |
| 最小化 QQ 音乐 | 卡片随 QQ 音乐隐藏，不悬浮在其他应用上 |
| 空闲时（无卡片、鼠标不在入口） | QQ 音乐不因 BetterDownload 出现持续 CPU 占用；卡片动画或悬停结束后自动停止逐帧计时 |
| 点击“查找并转换” | 按钮旁显示查找结果；未识别目录或没有歌曲时也有提示 |
| 关闭再打开设置 | 已选项保留，后台自动转换继续 |
| 点击右上角“检查更新” | 按钮显示“正在检查…”，随后变为“已是最新”；有新版本时为“下载 vX”，点击后在浏览器中打开本仓库的发布页；断网时显示“检查失败，重试”。“已是最新”和失败提示约 3 秒后恢复为“检查更新”，可再次点击；“下载 vX”保持 |

“预览”使用虚构歌曲，不生成歌曲文件。设置页的作者、功能说明和主要文案沿用网易云版。

## 全自动下载

1. 在 QQ 音乐里正常下载一首已有下载权限的受支持 VIP 歌曲。
2. 不点击 BetterDownload 的扫描按钮，等待卡片显示转换完成。
3. 从完成卡片打开输出目录，确认原文件与 `unlock` 中的输出都存在。
4. 用其他播放器完整播放输出，核对时长、采样率、声道、位深、标签及可用的封面。
5. 重复触发同一下载，已完成且内容未变的文件应跳过；已有同名输出应保留。
6. 在 QQ 设置中改变下载路径、分类或命名方式，再正常下载一首；程序应识别新位置并保留子目录。
7. 重开 QQ 音乐，已有目录中的待转换下载应自动补处理。

首次使用时，默认 Windows 下载目录中的 `VipSongsDownload` 会自动识别。自定义的旧目录需通过新下载事件记录，记录后无需重复选择。

真实音频已实测 QQ 音乐 22.71 x86 的 FLAC（SQ、臻品全景声、臻品母带）和 OGG（标准、HQ）。杜比全景声 MP4 和旧 QTag / QMC2 V1 仅通过合成夹具验证。MP3、M4A、QMC1 暂未支持。

## 跨版本兼容

以下项目在新的 QQ 音乐版本上逐项记录；`tests.exe --real-client` 通过不能代替应用内检查：

- [ ] 0.1.4 安装后，QQ 音乐 22.71 的顶部入口、设置页和卡片与 0.1.3 表现一致；设置页显示当前状态和开关，不再是空白状态。
- [ ] 在目标版本上运行 `tests.exe --real-client <QQ 音乐安装目录>`，记录各层识别结果。
- [ ] 本地密钥接口为“未实测”的版本：新下载能转换并通过整曲校验，设置页说明接口未实测。
- [ ] 界面未适配的版本：顶部不出现入口；Alt+空格 窗口菜单中的“BetterDownload 设置”打开独立窗口，窗口中说明哪一层未适配；转换卡片出现在 QQ 音乐窗口右下角；任何时候都不自动弹出设置窗口。
- [ ] 密钥接口未适配的版本：新格式下载保留，设置页说明原因；文件内自带密钥的旧格式照常转换。

## 安装、重启和更新

以下项目需要记录真实机器结果，不能由隔离测试替代：

- [ ] QQ 音乐退出后重新打开，顶部入口和自动转换恢复。
- [ ] Windows 重启后，后台程序自动运行。
- [ ] 更新时不强制结束 QQ 音乐；新版本暂存，正常退出后生效。
- [ ] QQ 音乐安装目录变化后，后台重新识别路径。
- [ ] 客户端密钥接口未适配时保留任务，明确提示原因。
- [ ] 卸载移除自动启动与入口；默认保留歌曲、设置和转换记录。
- [ ] 勾选“同时删除插件数据”后卸载：`%LOCALAPPDATA%\QQM-BetterDownload` 中的设置、转换记录、状态文件和缓存被删除（QQ 音乐运行时在其退出后删除），全部清空后目录本身也被删除；歌曲和 `unlock` 中的输出保留。卸载后立即重装时，不再删除新安装的数据。
- [ ] 卸载后立即再次运行安装器并点击“安装”，安装保持完整，QQ 音乐重开后入口恢复。
- [ ] 从网络下载的单个 `BetterDownload-Setup.exe` 可完成安装；重启 Windows 后自动启动不出现安全提示。
- [ ] 安装器没有任何打开设置的入口；从 0.1.3 更新后，开始菜单中旧版的“BetterDownload 设置”快捷方式被移除。
- [ ] 安装完成后大按钮变为“完成”，提示中给出设置入口的位置；QQ 音乐运行中更新时提示新版本已准备好，退出后自动切换。
- [ ] 卸载在窗口内确认，焦点默认在“取消”，按回车不会直接卸载。
- [ ] Windows“已安装的应用”中，BetterDownload 的“修改”打开安装器窗口，“卸载”进入窗口内确认，“取消”直接关闭。
- [ ] 安装器跟随 Windows 浅色 / 深色模式，切换系统模式时即时更新；100% / 150% / 200% 缩放下文字清晰、布局不错位。
- [ ] 界面未适配的 QQ 音乐版本上，“设置入口”一行显示窗口菜单（Alt+空格），菜单中的“BetterDownload 设置”可以打开设置。

在线适配清单和程序自动下载更新尚未实现，不能把未来任意客户端升级列为已通过。

## 开发预览

只检查外观时，可使用 `build/BetterDownload.exe --card-demo`。该模式使用独立预览窗口，不读取下载密钥、不处理歌曲、不保存设置；正式插件在 QQ 音乐内部显示。
