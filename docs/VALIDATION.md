# 验证记录

截至 0.1.3，程序检查 **135 项**、安装器检查 **18 项** 通过。所有自动化夹具为原创正弦音和虚构元数据。已移除外部子窗口路线及其专用测试，数量不能与旧路线直接比较。

## 已验证

- 关闭回归：加载中退出、已加载退出、原生控制器先关闭，以及退出后的状态/预览请求。旧实现能在提前关闭控制器时复现 CoreWebView2 disposed / get_Profile 异常；新实现通过相同故障注入。
- 主窗口识别：忽略启动辅助窗；主窗口被重建后重新接入；普通最小化和隐藏窗口保留已识别窗口；就绪信号按进程及启动时间隔离。
- 独立 WebView2 预览：开关、选项、扫描反馈、预览卡片、Esc 返回、窄窗口和关闭清理。
- 本地页面通信：UTF-8 状态与动作往返；拒绝错误地址令牌、Host、Origin、动作、类型和超限请求；不提供任意文件路由。
- 未匹配 GF 组件指纹时不启用私有界面接口。
- 自动路径：启动补处理默认目录；只接收 VIP 下载；新位置自动记忆、回填并跨重启保留；无目录时扫描也返回结果。
- 以原生桥相同格式写入带 `\\?\` 本地磁盘前缀的 UTF-16 事件，验证转换和目录回填；拒绝扩展 UNC、设备及相对路径。首次发现窗口时也覆盖已最小化的情况。
- 通知状态去重、成功 / 失败与重试、通知过滤、标准和简洁样式、封面缺失回退。
- 卡片窗口不抢焦点、鼠标悬停保持、离开后计时收起。
- 加密音频中的标签读取、随机读取边界、源文件保持不变、重复转换跳过。
- QTag 与 QMC2 V1 文件内密钥：合成下载转换后与原始 FLAC 逐字节一致。
- 独立原生宿主：CopyFileW、CopyFileExW、MoveFileW、MoveFileExW 成功后传递最终路径；过滤失败和无关操作；保持系统错误码；停用后恢复原操作。
- 安装器隔离测试：清单和哈希校验、重复安装、路径越界拒绝、损坏回退、截断包拒绝、同版本修复、保留设置和未知文件。
- 安装位置检查：普通临时目录通过；实际文件位置与声明路径不同时拒绝激活。额外在继承 AppData 重定向的启动环境中复现并确认拦截，探测文件自动清理。

## 真实音频验证

本机 QQ 音乐 22.71 x86 的 musicex V1 FLAC 样本已完成整曲转换、标签读取和本地封面写入验证：

- 192 kHz、24 bit、双声道。
- 32,977,433 个采样帧，时长约 171.757 秒。
- 独立解码得到的 PCM MD5 与 FLAC STREAMINFO 一致。
- 加密源读取的歌曲标签与输出一致；本地缓存封面与输出内嵌封面一致。
- 原文件保留。歌曲本体、真实标签、路径、密钥和验证用私人资料不提交。

## 真实客户端界面与安装

- 22.71 x86 已创建进程内 GF 入口与 HTML 控件，设置可打开，预览请求到达后台。
- 卡片使用透明纹理由 GF 绘制；已观察到右下角简洁卡片，以及收起后无黑色矩形残留。
- 正式用户目录安装曾因路径文本校验拒绝界面连接；改为文件身份校验后，实际安装版本返回原生界面已连接。
- 随后正常重开暴露了另一项安装问题：文件实际写入启动环境的私有缓存，QQ 音乐从声明路径访问时返回路径不存在。已保留旧数据备份，在共享的真实用户目录重装；实际安装版入口出现、设置页打开，后台报告 `nativeReady: true`。
- 完整退出 QQ 音乐后重新启动，确认产生新的客户端进程和工作进程，入口及设置页恢复，使用用户目录中的正式安装版本。
- 最终安装版在 QQ 音乐保持最小化时完成重新接入；积压的真实下载事件被自动处理，记住新下载目录并清空队列。输出为有效 FLAC，源文件及输出均与转换记录中的 SHA-256 一致。
- 登录自动启动项、稳定启动器、版本清单和已安装文件哈希已检查。没有通过重启 Windows 验证完整登录流程。
- 最后追加的圆角、鼠标焦点框、页脚间距、入口悬停 / 按下 / 双击、重新开页动效和预览样式连续切换需要继续实机复测。电脑控制被用户 Esc 中断后已停止操作，不能将程序检查当作这些效果已验收。

## 0.1.3 界面重设计与性能

- 进度卡片改为浅色（白底、柔和阴影、品牌绿 #1ECC94）：四种状态经离线 WPF 预览渲染并核对，README 与预览图已更新；真实 QQ 内部右下角合成显示仍需实机复测。
- 顶部入口改为 QQ 原生单色图标 + 主题绿悬停 / 按下（无底色方块），尺寸对齐相邻按钮；`NativeUiSession` 运行时换色，130 项程序检查通过。真实顶栏观感需实机复测。
- 去除常驻托盘：工作进程随 QQ 音乐启动接入、退出停止，不再显示托盘图标或气泡；原生界面未就绪时仅记录到运行状态。
- 性能：原生逐帧时钟由常驻 16ms 轮询改为按需启停——空闲时停表，卡片动画 / 收起或鼠标移动到入口时才运行，鼠标经 `WM_MOUSEMOVE` 唤醒。改动为代码级，构建与 130 项检查通过；QQ UI 线程实际占用下降需在真实客户端用性能计数器复测。
- 应用内设置页改为长轮询，打开 / 关闭 / 状态变化即时送达，空闲每 15 秒一次请求；关闭时页面预先隐藏，连续点击入口只重播一次淡入。本地页面测试新增长轮询挂起、即时应答、过期版本与非法参数检查（共 135 项通过）；用模拟服务在浏览器中核对了连续开关的页面状态切换。真实 QQ 内 GF 浏览器的连续点击观感需实机复测。
- LOGO 改为 QQ 音乐标志配色（青绿渐变、白色箭头、黄色锁头）；ICO、README 封面与设置页截图已重新生成并逐一核对。
- 安装器重做为深色 BetterNCM-Installer 风格：LOGO、信息面板、按状态变化的单一主操作（安装 / 更新 / 修复）、打开设置和卸载；18 项安装器检查通过，窗口外观已截图核对。本机 QQ 音乐装在 D 盘，新安装器从注册表识别为“22.71 · 已适配”，旧版只查系统盘。
- 修正卸载后立即重装的冲突：残留清理进程与安装器共用锁，发现已重新安装即退出。“打开设置”改在后台执行、改为打开而非切换，并前置 QQ 音乐窗口。以上为代码与离线检查；下载后首次运行（SmartScreen、下载标记移除）和“打开设置”前置窗口需实机复测。
